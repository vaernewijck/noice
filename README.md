
  # Noice

  This is a code bundle for Noice, a generative design tool. The original project is available at https://www.figma.com/design/NG649Tc4G2XDzjgD338D5Q/Generative-Color-Tool.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.
